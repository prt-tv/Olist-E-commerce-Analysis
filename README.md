# Olist-E-commerce-Analysis

# Project Overview
An end-to-end e-commerce data analysis project using PostgreSQL/SQL and Tableau to explore Olist sales, customers, products, sellers, payments, and customer reviews.

The project focuses on understanding sales performance, customer behavior, product performance, payment patterns, seller performance, and customer satisfaction through data exploration and business-focused analysis.

## Business Objectives
Understand overall order and revenue performance.
Identify customer and geographic trends.
Analyze product and category performance.
Understand seller performance.
Analyze payment methods and payment behavior.
Evaluate customer review patterns.
Identify insights that can support better business decisions.

## Tools Used
PostgreSQL / SQL — Data cleaning, exploration, validation, and analysis
Tableau — Data visualization and dashboard creation
Data Cleaning & Validation

Before analysis, the data was reviewed for:

Duplicate records
Date-format consistency
Incorrect or invalid values
Data quality issues that could affect the analysis
